# Навыки Нейриума

Каталог навыков (skills) персонального AI-ассистента [Нейриум](https://neurium.ru).
Навык — директория с `SKILL.md`: инструкция ассистенту, когда и как выполнять
определённый класс задач, плюс справочные материалы и шаблоны.

## Лицензии

- Навыки Нейриума — MIT (файл `LICENSE` в корне).
- Навыки, отмеченные Apache-2.0, — адаптации навыков Anthropic
  ([anthropics/skills](https://github.com/anthropics/skills),
  [anthropics/knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins)).
  Лицензия источника сохранена рядом с навыком (`LICENSE.txt`), происхождение
  указано в самом `SKILL.md`.
