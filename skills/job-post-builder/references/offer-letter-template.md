# Шаблон письма-оффера

Используй как базовый шаблон для файла оффера (docx). Замени все поля `[В КВАДРАТНЫХ СКОБКАХ]` реальными значениями или оставь понятными плейсхолдерами. Каждый плейсхолдер помечай явно, чтобы было видно, что ещё нужно заполнить перед отправкой.

> Оффер в РФ — это письмо-предложение, а не юридический документ. Юридически всё закрепляет **трудовой договор**, который стороны подписывают при выходе (в первый рабочий день) по ТК РФ. Шаблон помогает подготовить письмо, но не заменяет кадровика или юриста.

---

## Шаблон

---

[ЛОГОТИП / ШАПКА КОМПАНИИ]

[ДАТА]

[ФИО КАНДИДАТА]

Здравствуйте, [ИМЯ КАНДИДАТА]!

Рады предложить вам должность **[ДОЛЖНОСТЬ]** в [НАЗВАНИЕ КОМПАНИИ]. Нам особенно понравилось [короткая тёплая деталь про кандидата — например, «как вы разобрали тестовое по маркетплейсам и какие вопросы задали про наши процессы»], и мы уверены, что вы отлично впишетесь в команду.

**Условия предложения**

| | |
|---|---|
| Должность | [ДОЛЖНОСТЬ] |
| Подразделение | [ОТДЕЛ] |
| Руководитель | [ФИО РУКОВОДИТЕЛЯ], [ДОЛЖНОСТЬ РУКОВОДИТЕЛЯ] |
| Занятость | [Полная / Частичная] |
| Дата выхода | [ПРЕДПОЛАГАЕМАЯ ДАТА ВЫХОДА] |
| Место работы | [АДРЕС ОФИСА / Удалённо / Гибрид — укажите дни в офисе, если есть] |
| Испытательный срок | [СРОК, до 3 месяцев по ТК РФ для линейных ролей] |

**Оплата**

Оклад — **[СУММА] ₽ [на руки / до вычета НДФЛ]**, выплата [два раза в месяц] в соответствии с принятым в [НАЗВАНИЕ КОМПАНИИ] графиком.

[ЕСЛИ ЕСТЬ — ПРЕМИЯ / ПРОЦЕНТ]
Дополнительно предусмотрена [премия / процент от продаж]: **[РАЗМЕР ИЛИ ФОРМУЛА]**, по результатам работы.

**Что предлагаем помимо оклада**

[Перечислите 3–5 значимых условий: ДМС, обучение за счёт компании, гибкий график, оборудование, компенсация связи/проезда и т.п. Детали — при выходе.]

**Оформление**

Трудоустройство оформляется по ТК РФ: в первый рабочий день мы подписываем трудовой договор, где закрепляются все условия. Предложение действует до **[ДАТА, ДО КОТОРОЙ ЖДЁМ ОТВЕТА]**.

[ЕСЛИ ПРИМЕНИМО — УСЛОВИЯ]
Предложение действительно при [прохождении проверки службы безопасности / предоставлении документов об образовании / положительных рекомендациях — удалите ненужное].

Будем рады видеть вас в команде [НАЗВАНИЕ КОМПАНИИ]. Если есть вопросы — пишите [КОНТАКТНОЕ ЛИЦО] на [КОНТАКТ].

С уважением,
[ФИО РУКОВОДИТЕЛЯ]
[ДОЛЖНОСТЬ]
[НАЗВАНИЕ КОМПАНИИ]
[ДАТА]

---

*Это письмо-предложение. Окончательные условия и права сторон закрепляет трудовой договор по ТК РФ. Шаблон не является юридической консультацией — при сомнениях сверьтесь с кадровиком или юристом.*

## Справочник полей

| Поле | Описание |
|---|---|
| [ЛОГОТИП / ШАПКА КОМПАНИИ] | Заменить реальной шапкой или убрать |
| [ДАТА] | Дата отправки письма |
| [ФИО КАНДИДАТА] | Полное имя |
| [ДОЛЖНОСТЬ] | Точное название как в вакансии |
| [ОТДЕЛ] | Команда или направление |
| [ФИО / ДОЛЖНОСТЬ РУКОВОДИТЕЛЯ] | Прямой руководитель |
| [ПРЕДПОЛАГАЕМАЯ ДАТА ВЫХОДА] | Целевая дата выхода |
| [СУММА] ₽ | Подтверждённый оклад — сверить перед отправкой; указать «на руки» или «до вычета НДФЛ» |
| [ИСПЫТАТЕЛЬНЫЙ СРОК] | До 3 месяцев по ТК РФ (до 6 — для руководителей) |
| [ПРЕМИЯ / ПРОЦЕНТ] | Удалить блок, если нет |
| [ДАТА, ДО КОТОРОЙ ЖДЁМ ОТВЕТА] | Обычно 3–5 рабочих дней от отправки |
| [КОНТАКТНОЕ ЛИЦО] | К кому кандидат обращается с вопросами |
